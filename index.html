Updating the timetable data

When new Scientia/SITS exports are available, commit them to the data/ folder and push to main. The Generate Data & Deploy GitHub Action will run automatically, regenerate all three data.js files, and redeploy this page.

You can also trigger a manual run from the Actions tab → Generate Data & Deploy to GitHub Pages → Run workflow.
